# TAV PRESS FORM

Сайт по проектированию, изготовлению, испытанию и модернизации пресс-форм.

## Сайт

[https://razilkik-ops.github.io/tav-press/](https://razilkik-ops.github.io/tav-press/)

## Локальная разработка

```bash
npm ci
npm run dev
```

## Проверка и сборка

```bash
npm run build
npm run test:seo
npm run test:sites
```

GitHub Pages публикуется автоматически из ветки `main` через `.github/workflows/deploy-pages.yml`.
